### 📂 Featured Projects

#### ⚡ [Smile Fotilo](https://github.com/ak1458/Smile-Fotilo-NEXT-js-app)
> A premium, immersive digital agency platform built using **Next.js 16**. It is designed with modular, highly aesthetic CSS, interactive micro-animations, and structured metadata for next-level visual experience and search engine optimization.

#### 🔒 [Sovereign Vault](https://github.com/ak1458/sovereign-vault)
> A next-gen local-first privacy vault employing zero-knowledge encryption. Designed with **TypeScript** and the native **Web Crypto API**, it ensures that user data is encrypted client-side before any synchronization, giving users complete digital sovereignty.

#### 🤖 [YouTube Bulk Optimizer](https://github.com/ak1458/youtube-bulk-optimizer)
> A workflow utility designed for content creators. Automates bulk organization of playlists and coordinates SEO optimization of titles, descriptions, and tags. Built with a futuristic UI, a built-in API quota tracker, and local timezone auto-schedulers.

#### 🛒 [PulseKart](https://github.com/ak1458/PulseKart-Nextjs-web-app)
> An enterprise-grade, full-stack e-commerce marketplace engineered with **Next.js 16**, **TypeScript**, and **PostgreSQL**. Features server-rendered storefronts, lightning-fast search queries, and dynamic inventory management.
